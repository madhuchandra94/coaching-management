# 🎓 Coaching Management System (Django)

## 📌 Overview

A Django-based web application designed to manage coaching institute operations such as staff management, student enquiries, class scheduling, and document handling.

---

## 🚀 Features

* Staff registration & management
* Student enquiry tracking
* Trainer class scheduling
* File upload (Aadhar, PAN, Salary Slip)
* Location management (Country, State, City via CSV import)

---

## 🛠 Tech Stack

* Python
* Django
* SQLite
* HTML, CSS

---

## 📂 Project Structure

```
coaching-management/
│── coachingmanagement/   # Main project settings
│── staffPortal/          # Core app
│── manage.py
│── requirements.txt
```

---

## ▶️ How to Run

```bash
git clone https://github.com/madhuchandra94/coaching-management.git
cd coaching-management
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
